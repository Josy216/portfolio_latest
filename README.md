## 💻 About This Portfolio App

This portfolio web application was crafted with:
- **React 19 & Vite 6** for lightning-fast bundling and modern performance.
- **React Router 7** for smooth client-side routing between the home view and detailed project breakdowns.
- **Custom HTML5 Canvas Particle Engine** delivering a dynamic, responsive starfield background.
- **Interactive Multi-Tab Dashboard:**
  - 📁 **Projects:** Filterable showcase with video modals, skill badges, and live demo links.
  - 👤 **About Me:** Professional background, stats, tech stacks, and direct links.
  - 🎥 **My Videos:** Filtered video player (Basics, Tools, Roadmaps, Full-Stack) pulling from YouTube.
  - 💬 **Testimonials:** Verified client video testimonial and feedback.
- **SEO & Social Optimization:** Rich Open Graph tags, Twitter cards, and Schema.org JSON-LD structured data.

## ⚙️ Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Josy216/portfolio_latest.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   npm run preview
   ```

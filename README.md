## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Josy216/portfolio_latest.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

4. Build production bundle:
   ```bash
   npm run build
   ```
